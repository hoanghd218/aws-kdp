# True Crime Noir Aesthetic Coloring Book

## Why This Idea
True crime is a massive entertainment category (podcasts, Netflix, books) but barely exists in coloring books. A noir detective aesthetic — fedora hats, magnifying glasses, crime scene tape, vintage typewriters — taps into this cultural obsession without being graphic. Emerging viral potential on TikTok/Instagram.
